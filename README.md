# Industrial Health Index (PdM)

Система ранней детекции деградации и оценки индекса здоровья подшипников качения на основе анализа вибрации: от классической физики (RMS) через снижение размерности (PCA) до классификации (Random Forest).

## Проблема

В вибрационных данных промышленного оборудования ранние признаки износа маскируются шумом, переходными режимами (пуск/остановка) и — при одновременной деградации нескольких узлов — общим ростом фонового уровня вибрации. Стандартные пороговые методы либо пропускают ранний износ, либо генерируют избыточные ложные тревоги.

## Датасет

[IMS Bearing Data Set](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/) — предоставлен Center for Intelligent Maintenance Systems (IMS), University of Cincinnati, распространяется через NASA Prognostics Data Repository.

- 4 подшипника Rexnord ZA-2115 на одном валу, 2000 об/мин, радиальная нагрузка 6000 фунтов
- Акселерометры PCB 353B33, частота дискретизации 20 кГц, 1с записи (20 480 точек) каждые 10 минут
- 3 теста "до отказа": **Set 1** (2 156 файлов, 8 каналов — 2 датчика на подшипник), **Set 2** (984 файла, 4 канала — 1 датчик на подшипник), **Set 4** (6 324 файла, 4 канала)
- Данные НЕ включены в репозиторий (`data/` в `.gitignore`) — скачать отдельно по ссылке выше и распаковать в `data/`

## Методология

Три последовательных подхода; каждый следующий закрывает конкретное ограничение предыдущего.

| # | Подход | Метод | Что показал |
|---|---|---|---|
| 1 | Physics-based | RMS + экспоненциальная аппроксимация | Работает для локализованных дефектов; подвержен «ловушке медианы» при одновременной деградации нескольких узлов (общая медиана растёт вместе с дефектным подшипником и маскирует ранний износ) |
| 2 | Statistical | PCA Health Index — PC1 по 7 признакам (RMS, kurtosis, skew, crest, energy, band_5_10k, spec_centroid) | Обнаруживает деградацию раньше RMS за счёт чувствительности к структуре сигнала, а не только к его энергии |
| 3 | ML | Random Forest, 52 признака (базовые + rolling mean/std + градиент), с инженерными фильтрами (маска приработки, порог уверенности, сглаживание) | Классификация состояния (Normal / Warning / Degradation / Critical), устойчивая к ложным тревогам |

## Ключевые результаты

- **Set 2, подшипник B1** (документированный отказ): RMS фиксирует начало деградации на ~117.5ч, PCA Health Index — на ~117.2ч; прогноз остаточного ресурса в момент детекции ~111ч.
- **Set 4, все 4 подшипника**: ML-пайплайн с фильтрами v3 (маска приработки 100ч, порог уверенности ≥80%, сглаживание 12ч) корректно проходит через известную «ступеньку» на подшипнике B4 (388ч) — локальный дефект, который стабилизировался и не должен давать ложную тревогу на протяжении следующих ~630ч.
- **Backtesting без подглядывания в будущее** (`test_partial_prediction`: признаки считаются на полном ряду, обрезка идёт уже после): на срезе Set 2 / B3 (97% данных) первое предупреждение — 127.3ч, критический статус — 152.5ч.
- **Важность признаков** (Random Forest): первое место — `spec_centroid_roll_mean`, сглаженное смещение спектрального центра тяжести. Физическая интерпретация: при деградации подшипника меняется характер фрикционного контакта, и энергия вибрации перераспределяется между частотными полосами раньше, чем растёт общая амплитуда (RMS).

## Известные ограничения

Спроектировано как честная фиксация того, что работает и что ещё нет, а не как отчёт «всё готово».

1. **Утечка данных в PCA Health Index.** Текущий PCA обучен на всей серии наблюдений, включая период деградации, — компонента «видела» аварию при подборе осей. Корректное решение — калибровка только на здоровом периоде (первые 20–50ч) — реализовано в классе `DensityGridMonitor`, но пока не подключено к основному пайплайну расчёта Health Index.
2. **Индексация каналов vs. физических подшипников в Set 1.** Set 1 — единственный из трёх наборов с 2 датчиками на подшипник (H и V, итого 8 каналов на 4 подшипника). Общая функция извлечения признаков нумерует колонки по порядку (`b1`…`b8`): для Set 2/4 (1 датчик = 1 подшипник) это соответствует физическим подшипникам напрямую, но для Set 1 даёт `b1`=B1_H, `b2`=B1_V, `b3`=B2_H, `b4`=B2_V, `b5`=B3_H, `b6`=B3_V, `b7`=B4_H, `b8`=B4_V. Формулировки о «подшипнике B6» или «B3/B4» применительно к Set 1 в более ранних версиях анализа относились к каналам, а не обязательно к физическим подшипникам 3 и 4 (реально отказавшим по документации NASA) — это стоит перепроверить с учётом карты выше, включая часть обучающих данных Random Forest, взятых из Set 1.
3. **Предсказание или описание.** Random Forest обучен на данных, где метка (момент начала деградации, FPT) уже известна, — это корректная методология обучения, но означает, что качество на тренировочных данных не равно качеству предсказания. Настоящая проверка — `test_partial_prediction()` на усечённых данных. Система выполняет раннюю детекцию деградации, а не точечный прогноз «часов до отказа» в общем случае.

## Структура репозитория

```
notebooks/
  industrial-health-index-pdm.ipynb   — весь анализ: EDA, 3 подхода, обучение, backtesting
```

## Как запустить

```bash
git clone https://github.com/czeberyak/industrial-health-index-pdm.git
cd industrial-health-index-pdm
pip install -r requirements.txt

# Скачать IMS Bearing Data Set (см. раздел "Датасет") и распаковать в data/

# Извлечь и закэшировать признаки для одного датасета:
python src/features_engine.py --data_path data/2nd_test

# Дальше — весь анализ в ноутбуке:
jupyter notebook notebooks/industrial-health-index-pdm.ipynb
```

## Стек

Python, pandas, NumPy, SciPy (FFT, статистика), scikit-learn (PCA, Random Forest), matplotlib / seaborn.

## Планы

- Интеграция `DensityGridMonitor` в основной расчёт Health Index — устранение утечки в PCA.
- Расширенный backtesting: несколько подшипников и долей среза (70 / 80 / 90 / 97%) со сводной таблицей раннего предупреждения.
- Интерактивное демо (Streamlit) по аналогии с [RSM Tg/LSS Predictor](https://epoxy-structural-ep1.streamlit.app/) из проекта epoxy_structural_ep1.
