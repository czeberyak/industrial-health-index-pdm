# ⚙️ Industrial Health Index: Predictive Maintenance (PdM)

Система предиктивной аналитики состояния подшипников качения на основе вибрационных данных. Проект минимизирует риски внезапных аварийных остановок оборудования за счет автоматического вычисления индекса здоровья (Health Index) и прогнозирования деградации узлов.

## 🎯 Цели проекта
* **Мониторинг:** Расчет индекса здоровья (HI) в режиме реального времени.
* **Диагностика:** Автоматическое обнаружение начала процесса деградации (Failure Point Tracking).
* **Прогнозирование:** Оценка остаточного ресурса подшипника для планирования ремонтных работ.
