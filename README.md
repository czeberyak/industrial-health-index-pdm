# Industrial Health Index (PdM)

Система обнаружения аномалий и оценки индекса деградации промышленного оборудования на базе неконтролируемого обучения (Unsupervised Learning).

## 🎯 Проблема
В производственных данных (датчики вибрации, температуры) аномалии часто «маскируются» под естественный шум или переходные процессы (пуск/остановка оборудования). Стандартные методы часто дают слишком много ложных срабатываний.

## ⚙️ Решение
Система использует PCA (метод главных компонент) для построения индекса деградации, что позволяет:
* Снизить размерность данных без потери ключевых признаков.
* Автоматически выделять паттерны «нормальной» работы.
* Детектировать отклонения, сигнализирующие о предаварийном состоянии подшипников или узлов вращения.

## 🏗 Структура
- `data/` — примеры телеметрии (или описание формата).
- `notebooks/` — EDA и процесс обучения модели.
- `src/` — основной движок обработки сигналов и аномалий.
